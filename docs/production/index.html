本番化実装ハンドオフ v1

グロースレンタカー予約・管理システム — 実装開始直前の設計パック

現在の公開版は本番利用 No-Go です。
localStorage を使う機能デモであり、認証・法務表示・予約競合制御・個人情報保護・監査・復旧は未実装です。受入チェック完了まで実在する顧客情報を入力しないでください。

設計パック

01 本番化ハンドオフ採用構成、信頼境界、予約 transaction、認証、法務、移行、実装順、未決事項。 02 現状監査再利用可・要置換・本番禁止の判定、実装根拠、仕様の矛盾。 03 データモデルテーブル、制約、索引、RLS、transaction 不変条件の実装前契約。 04 OpenAPI 3.1公開・会員・管理 API、認証、冪等性、楽観 lock、error schema。 05 受入・Go/No-Goチケット、法務、完了条件、security・競合・移行・復元試験。 06 法務公開ページ案貸渡約款、料金・取消、特商法、privacy、cookie等の公開前テンプレート。

推奨する技術方針（承認前）

第一候補Supabase / PostgreSQL / Auth / Edge Functions、東京リージョン
予約の正PostgreSQL。半開区間 [start_at, end_at)、asset 単位で直列化
価格・権限サーバーが再計算・再認可。ブラウザ値を信用しない
管理者別サブドメイン、MFA、RBAC、拠点 scope、追記監査
法務許可・料金・貸渡約款・privacy・最終確認画面を責任者/専門家承認後に公開
現行 UI再利用可。localStorage / 認証 / 予約 / 料金処理は置換

次に行うこと

  1. ハンドオフの事業判断 A〜P を owner 付きで承認する。
  2. 事業者・許可・約款・料金・取消・個人情報の確定値を法務テンプレートへ入力し、専門家確認を受ける。
  3. 受入資料の Phase 0 と Definition of Ready を完了する。
  4. 最初の実装 PR を環境分離と DB migration に限定して開始する。
