個人情報のお取り扱いについて

当社は、貸渡契約の締結および履行のために、借受人および運転者の氏名、住所、電話番号、電子メールアドレス、運転免許証の記載事項その他必要な個人情報を取得します。

取得した個人情報は、次の目的で利用します。

  1. 予約の受付、本人確認および運転資格の確認。
  2. 車両の貸渡しおよび返還、料金の請求および精算。
  3. 事故、故障、盗難、交通法規違反その他のトラブルへの対応。
  4. 保険金の請求および補償制度に関する手続き。
  5. 法令に基づく記録の作成、保存および届出。
  6. 貸渡契約に関する連絡、お問い合わせへの対応。
  7. 当社のサービスに関するご案内。配信停止のお申し出があった場合は、契約の履行に必要な連絡を除き、ご案内を停止します。

当社は、法令に基づく場合その他個人情報保護法により認められる場合を除き、あらかじめ本人の同意を得ることなく個人データを第三者に提供しません。

保険会社、事故の相手方その他の関係者への情報提供が必要となる場合は、法令上本人の同意を要しない場合を除き、提供先、利用目的および提供する情報の範囲を示したうえで、本人の同意を得て提供します。

当社は、利用目的の達成に必要な範囲で個人情報の取扱いを委託することがあります。この場合、委託先に対して必要かつ適切な監督を行います。

個人情報の管理、開示、訂正、利用停止等の請求方法およびお問い合わせ先は、当社のプライバシーポリシーに定めるところによります。

貸渡契約の締結および履行に必要な情報をご提供いただけない場合、当社は貸渡契約の締結をお断りすることがあります。

第1章　総則

第1条 (約款の適用)

  1. この約款は、株式会社Skyward Growth（以下「当社」といいます）が「グロースレンタカー」の名称で行うレンタカーおよびキッチンカーの貸渡しについて、当社と借受人との間に成立する貸渡契約に適用します。
  2. この約款に定めのない事項については、法令または一般の慣習によります。
  3. 当社は、この約款の趣旨に反しない範囲において、書面または電磁的方法による特約に応じることがあります。この場合、その特約はこの約款に優先します。ただし、法令の強行規定に反する特約は適用しません。
  4. この約款において「借受人」とは当社と貸渡契約を締結した方をいい、「運転者」とは当社が承認し、貸渡証に記載した運転者をいいます。「車両」とは当社が貸し渡す自動車をいい、付属品および装備品を含みます。
  5. 当社は、貸渡契約の締結前に、この約款、適用する料金表および補償条件を借受人が確認できる方法で提示します。契約締結後にこれらを変更した場合も、既に成立した契約には、法令に従って変更が適用される場合または借受人と合意した場合を除き、契約締結時の条件を適用します。

第2章　予約

第2条 (予約の申込み)

  1. 予約のお申込みは、当社の予約サイト、電子メール、公式LINEその他当社が定める方法により承ります。
  2. お申込みに際しては、車両またはクラス、貸渡しの日時および場所、返還の日時および場所、借受人および運転者の氏名・連絡先、ご希望のオプションおよび補償、その他貸渡しに必要な事項をお申し出いただきます。
  3. 予約は、当社がお申込みを承諾し、その旨を借受人に通知したときに成立します。
  4. 当社は、予約の成立前に、適用する料金、キャンセル条件その他の主要な利用条件を提示します。
  5. 予約の成立は貸渡契約の成立を意味するものではありません。貸渡契約は第9条の定めにより成立します。

第3条 (予約の変更)

  1. 借受人は、貸渡しの開始前に、当社に対して予約内容の変更を申し出ることができます。
  2. 当社は、車両の空き状況その他の事情により、変更のお申し出に応じられない場合があります。
  3. 変更により料金に増減が生じるときは、変更後の条件および料金を提示し、借受人の同意を得て精算します。
  4. 変更を取消しおよび新たな予約として取り扱う条件は、予約の成立前に提示するキャンセル規定によります。当社は、変更の申出のみを理由として、事前に提示していないキャンセル料を請求しません。

第4条 (予約の取消し)

  1. 借受人は、貸渡しの開始前に、予約を取り消すことができます。
  2. 借受人の都合により予約が取り消されたときは、予約の成立前に提示したキャンセル規定に従い、取消しの時期および車両区分に応じたキャンセル料をいただきます。キャンセル規定は、特定商取引法に基づく表記に掲載します。
  3. 貸渡しの開始予定時刻を経過しても借受人から連絡がなく、当社が合理的な方法で連絡を試みても連絡が取れないときは、当社は予約を取り消すことができます。この場合の取扱いは、事前に提示した無断キャンセルの規定によります。
  4. 天災、悪天候による交通の途絶その他借受人の責めに帰することができない事由により利用できない場合は、当社と借受人で事情を確認し、その事由により利用が客観的に困難であると認められるときは、キャンセル料をいただきません。
  5. 当社の責めに帰すべき事由により予約を取り消す場合は、キャンセル料をいただかず、受領済みの料金を返還します。
  6. キャンセル料は、法令により認められる範囲で請求するものとします。

第5条 (代替車両)

  1. 当社は、車両の故障、事故、先行する借受人からの返還の遅延その他の事由により予約された車両を提供できないときは、借受人に事情を説明し、用途、乗車定員その他の予約条件を踏まえた代替車両の提供に努めます。
  2. 代替車両による貸渡しは、借受人の承諾を得て行います。
  3. 代替車両の料金が予約された車両の料金を上回るときも、その差額はいただきません。下回るときは、代替車両の料金を適用します。
  4. 借受人が代替車両による貸渡しを承諾しないときは、予約を取り消し、キャンセル料をいただかず、受領済みの料金を返還します。

第6条 (車両を提供できない場合の取扱い)

  1. 当社が予約された車両または借受人の承諾した代替車両を提供できない場合は、受領済みの料金を返還します。
  2. 当社の責めに帰すべき事由により車両を提供できなかった場合の損害賠償は、法令に従って取り扱います。
  3. 当社の責めに帰することができない事由により車両を提供できなかった場合は、法令上責任を負う場合を除き、借受人に生じた交通費、宿泊費、逸失利益その他の損害について責任を負いません。

第3章　貸渡し

第7条 (貸渡手続き)

  1. 借受人は、当社が指定する貸渡場所において、貸渡契約の締結に必要な手続きを行うものとします。
  2. 借受人が運転する場合および運転者として登録するすべての方は、有効な運転免許証をご提示ください。当社は、必要に応じてその他の本人確認書類の提示を求め、運転免許証等の写しを取得することがあります。
  3. 運転者は、当該車両を運転するために必要な免許を有し、当社が承認した方に限ります。
  4. 借受人が未成年である場合は、親権者その他の法定代理人の同意を必要とします。
  5. 借受人は、登録する運転者にこの約款および補償条件を確認させるものとし、当社は各運転者から、運転者に適用される義務についての同意を取得します。
  6. 借受人は、借受人としてこの約款に定める義務を負います。借受人と運転者の連帯責任を別途定める場合は、その対象となる義務を明示し、双方の同意を得るものとします。

第8条 (締結の拒絶)

  1. 当社は、次の各号のいずれかに該当するときは、貸渡契約の締結をお断りすることがあります。
    1. 必要な運転免許証または本人確認書類が提示されないとき、または運転者が必要な免許を有しないとき。
    2. 運転者が酒気を帯びていると認められるとき、または薬物、疾病、疲労その他の理由により安全な運転ができないおそれがあると認められるとき。
    3. 借受人または運転者が暴力団その他の反社会的勢力に該当し、またはこれらと密接な関係を有すると認められるとき。
    4. 過去の未払料金、重大な約款違反その他の客観的な事情により、契約の履行が期待できないと認められるとき。
    5. 無断転貸、違法な有償運送その他禁止行為を行う具体的なおそれがあると認められるとき。
    6. 貸渡しの判断に影響する重要な事項について、事実と異なる申告があったとき。
    7. その他、安全な貸渡しまたは適法な利用が困難である合理的な理由があるとき。
  2. 借受人または運転者の責めに帰すべき事由により締結をお断りした場合のキャンセル料は、事前に提示したキャンセル規定および法令に従って取り扱います。
  3. 当社側の事情により締結をお断りした場合は、キャンセル料をいただかず、受領済みの料金を返還します。
  4. 締結の拒絶に関して当社の責めに帰すべき事由がある場合の損害賠償は、法令に従って取り扱います。

第9条 (契約の成立)

  1. 貸渡契約は、借受人と当社が貸渡条件に合意し、当社が貸渡証を交付して車両を引き渡した時に成立します。
  2. 借受期間は、貸渡証に記載した貸渡しの日時から返還の日時までとします。
  3. 貸渡証、契約時に提示した料金表、補償条件および合意した特約は、貸渡契約の一部を構成します。
  4. 当社は、借受人が契約時の約款および関連条件を後から確認できるよう、書面の交付その他適切な方法により提供します。

第10条 (貸渡料金)

  1. 貸渡料金は、基本料金、オプション料金、補償料金、割増料金その他契約前に提示する料金表によります。消費者向けの料金は、消費税込みで表示します。
  2. 料金のお支払いは、原則として貸渡場所における現地決済（現金またはクレジットカード）によります。法人および行政機関のお客様は、事前の審査および合意のうえ、請求書払い（月次一括を含みます）をご利用いただけます。
  3. オンラインでの事前決済は取り扱いません。
  4. 割引の適用条件、対象料金、超過料金その他の追加料金は、契約前に提示する料金表によります。
  5. 有料道路料金、駐車料金、燃料代その他借受期間中に生じた実費は、借受人の負担とします。
  6. 当社が追加料金または実費を請求する場合は、その内容、金額および計算根拠を借受人に説明します。

第11条 (借受条件の変更)

  1. 借受人は、借受期間中に返還の日時、返還場所または運転者を変更しようとするときは、あらかじめ当社に申し出て承諾を得るものとします。
  2. 当社は、その後の予約状況、点検整備の予定その他の事情により、変更のお申し出に応じられない場合があります。
  3. 変更により料金に増減が生じるときは、変更後の条件および料金を提示し、借受人の同意を得て精算します。
  4. 運転者の追加または変更については、第7条の確認および同意の手続きを行います。

第12条 (点検整備および確認)

  1. 当社は、貸渡しに際し、法令に従って必要な点検整備を行い、安全に運行できる状態で車両を引き渡します。
  2. 借受人は、引渡し時に当社係員とともに、外装、内装、装備品、燃料の量および備付書類を確認します。当社が認める場合は、写真その他の方法によって確認することができます。
  3. 当社は、既存の傷、汚損、装備品の不足その他の異状を、確認書、写真その他適切な方法で記録し、借受人と共有します。
  4. 借受人は、確認時または利用開始後に既存の異状に気付いた場合、速やかに当社へご連絡ください。
  5. 返還時に異状が認められた場合は、貸渡し前後の記録、損傷の状況その他の客観的な事情に基づいて、発生時期および責任を確認します。引渡し時に申告がなかったことのみをもって、借受人の責任とするものではありません。

第13条 (貸渡証の交付・携帯)

  1. 当社は、貸渡しに際して、法令に従った貸渡証を借受人に交付します。
  2. 借受人および運転者は、借受期間中、貸渡証を車内に備え付け、または法令上認められる方法で携帯するものとします。
  3. 貸渡証を紛失し、または汚損したときは、速やかに当社にご連絡ください。

第4章　使用

第14条 (管理責任)

  1. 借受人および運転者は、善良な管理者の注意をもって車両を使用し、保管するものとします。
  2. 借受人は、登録した運転者にこの約款および補償条件を周知し、禁止行為を行わせないよう必要な管理を行うものとします。
  3. 借受人および運転者は、当社が承認し、貸渡証に記載した運転者以外の者に車両を運転させてはなりません。
  4. 車両を離れるときは必ず施錠し、鍵および備付書類を適切に管理するものとします。

第15条 (日常点検整備および燃料)

  1. 借受人および運転者は、法令に従って必要な日常点検を行い、異状がないことを確認して車両を運行するものとします。
  2. 運行中に異状を認めたときは、安全を確保して運行を中止し、当社にご連絡ください。
  3. 使用する燃料の種類、貸渡し時および返還時の燃料の取扱いは、契約前に提示し、貸渡証その他の確認書類に記録した条件によります。
  4. 所定の給油を行わずに返還した場合の燃料精算額は、契約前に提示した単価および計算方法によります。
  5. タイヤの空気圧、冷却水、ウォッシャー液等について補充または措置が必要となった場合は、当社にご相談ください。
  6. 当社の指示により必要な費用を支出した場合は、その内容を確認して当社が精算します。緊急のため事前の連絡が困難であった場合は、措置の必要性および費用の相当性を確認し、法令に従って取り扱います。

第16条 (禁止行為)

借受人および運転者は、次の行為をしてはなりません。

  1. 酒気帯び、薬物等の影響その他安全な運転ができない状態での運転。
  2. 車両の第三者への転貸、または登録されていない者への運転の許可。
  3. 必要な運転免許を有しない者による運転。
  4. 法令に違反する旅客または貨物の有償運送。当社の承諾は、法令上必要な許可等に代わるものではありません。
  5. 当社が承認した用途以外の営業目的での使用。
  6. 火薬類、高圧ガス、毒物その他の危険物の輸送。ただし、法令に適合し、当社がキッチンカーの利用条件として明示的に承認した燃料等は、その条件の範囲で使用できます。
  7. 当社が指定する条件に反するペットの同乗。
  8. 車内での喫煙。加熱式たばこおよび電子たばこを含みます。
  9. 乗車定員または最大積載量を超える使用。
  10. 競争、競技、曲技、試験その他これらに類する走行への使用。
  11. 車両を担保に供すること、売却すること、無断で改造すること、部品または装備品を取り外すこと。
  12. 当社の承諾なくステッカーの貼付、塗装その他外観の変更を行うこと。キッチンカーの装飾を含みます。
  13. 通行が禁止されている場所への乗り入れ、車両に適さない河川敷・海浜等での走行その他著しい負担をかける使用。
  14. 犯罪行為その他の違法行為への使用。
  15. 当社の承諾なく車両を国外に持ち出すこと。

禁止行為があった場合の解除および損害賠償は、第27条および第29条によります。特別な清掃または修復を要する場合の費用は、契約前に提示した料金表または合理的な実費に基づき、その内容を説明して請求します。同一の損害について重複して請求することはありません。

第17条 (違法駐車等の措置)

  1. 借受人および運転者は、自らの行為による駐車違反その他の交通法規違反について、責任と負担をもって対応するものとします。
  2. 放置駐車違反があった場合は、速やかに管轄の警察へ連絡し、指示に従って必要な手続きを行うとともに、当社にご連絡ください。
  3. 当社が車両の使用者として放置違反金等を負担した場合は、法令に従い、責任を負う借受人にその負担額を請求することがあります。
  4. 前項の対応に関する事務手数料を請求する場合は、契約前に提示した金額または計算方法によります。
  5. 借受人および運転者は、違反処理の確認に必要な範囲で、当社への報告および書類の提示に協力するものとします。
  6. 当社が回収した違反金相当額について、その後還付を受けるなど負担が解消した場合は、精算して返還します。

第5章　返還

第18条 (返還責任)

  1. 借受人は、貸渡証に記載した日時および場所において、車両、付属品、装備品、鍵、貸渡証および備付書類を返還するものとします。
  2. 返還は、原則として当社係員の立会いのもとで行います。対応可能な時間は、予約時および貸渡証により案内します。
  3. 当社が事前に承認した場合は、指定する手順により立会いによらない返還を行うことができます。
  4. 返還が遅れるおそれがあるときは、返還予定時刻までに当社へ連絡し、承諾を得るものとします。
  5. 借受人の責めに帰すべき事由により指定場所まで返還できない場合は、必要かつ合理的な回収費用を借受人の負担とします。

第19条 (返還時の確認)

  1. 当社は、返還時に外装、内装、装備品、燃料の量および走行距離を確認します。
  2. 異状が認められた場合は、その内容を記録し、貸渡し時の記録等と照合したうえで借受人に説明します。賠償については第27条によります。
  3. 立会いによらない返還の場合の返還完了時点は、指定場所への駐車、施錠、鍵の返却および返還連絡等について、事前に合意した手順を完了した時点とします。
  4. 当社は、立会いによらない返還後、合理的な期間内に車両を確認します。返還時の写真、返還連絡、当社の確認記録その他の事情に基づいて状態を確認し、返還後に発生した損害を借受人に負担させることはありません。ただし、返還手順の不履行等により借受人に責任がある場合は、この限りではありません。

第20条 (借受期間変更時の料金)

  1. 借受人の都合で予定より早く返還する場合の料金および返金は、契約前に提示した中途解約・精算条件によります。返金しない条件を設ける場合も、法令により認められる範囲で適用します。
  2. 当社の承諾を得て返還日時を延長したときは、合意した追加期間に対応する料金をいただきます。
  3. 当社の承諾なく返還日時を経過したときは、契約前に提示した料金表に基づく超過料金をいただきます。
  4. 無断延長に伴う追加料金または損害賠償を請求する場合は、事前に提示した条件および法令によるものとし、同一の損害について重複して請求しません。
  5. 当社の責めに帰すべき事由により早期返還となる場合は、未使用期間に対応する料金を返還します。
  6. 料金および精算条件は、特定商取引法に基づく表記および車両と料金に掲載します。

第21条 (返還場所)

  1. 返還場所は、貸渡証に記載した場所とします。
  2. 当社の事前の承諾を得た場合は、他の指定場所に返還することができます。追加料金が生じる場合は、その金額を提示し、借受人の同意を得るものとします。
  3. 当社の承諾なく指定場所以外の場所に車両を置いた場合は、借受人の責任の範囲で、必要かつ合理的な回収費用および回収に必要な期間に対応する料金を請求することがあります。当社は、合理的な範囲で速やかな回収に努めます。

第22条 (不返還の措置)

  1. 返還日時を経過しても車両が返還されず、当社が合理的な方法で連絡を試みても借受人が応じない場合は、当社は第29条に従って貸渡契約を解除し、法令に従った回収措置をとることができます。
  2. 当社は、必要に応じて警察へ相談または届出を行うことがあります。
  3. 借受人に責任がある場合は、必要かつ合理的な回収費用、返還までの期間に対応する料金および当社に生じた損害を、重複しない範囲で請求します。

第6章　故障・事故・盗難

第23条 (故障時の措置)

  1. 車両に故障または異状が生じたときは、安全を確保して運行を中止し、当社にご連絡ください。
  2. 修理、部品交換その他の措置は、原則として当社の指示に従って行ってください。ただし、人命の保護または損害の拡大防止のために緊急の措置が必要な場合は、必要な措置を講じたうえで速やかに報告してください。
  3. 借受人に責任のない故障の場合は、当社は修理または代替車両の手配に努めます。
  4. 費用の負担は、故障の原因、措置の必要性、保険の適用その他の事情を確認し、法令および契約条件に従って決定します。

第24条 (事故時の措置)

  1. 事故が生じたときは、直ちに運行を中止し、負傷者の救護、道路上の危険防止その他法令に定める措置を講じたうえで、警察へ届け出るとともに、当社にご連絡ください。
  2. 借受人および運転者は、事故の状況、相手方の氏名および連絡先、加入保険その他必要な事項を報告し、事故対応および保険手続きに協力するものとします。
  3. 当社または保険会社との事前の協議なく、当社の負担または保険金の支払いに影響する示談その他の合意を行ってはなりません。
  4. 警察への届出または当社への連絡を怠った場合、保険約款または補償制度の適用条件により、保険金の支払いや補償を受けられないことがあります。救護等により直ちに連絡できないやむを得ない事情がある場合は、連絡可能となり次第ご連絡ください。

第25条 (盗難時の措置)

  1. 車両、付属品または装備品が盗難に遭ったときは、直ちに警察へ届け出るとともに、当社にご連絡ください。
  2. 借受人および運転者は、盗難届の受理番号その他必要な事項を報告し、警察および保険会社の手続きに協力するものとします。
  3. 盗難に関する賠償責任は、鍵の管理状況その他の事情を確認し、第27条、保険約款および補償条件に従って取り扱います。盗難が発生したことのみをもって、借受人の責任とするものではありません。

第26条 (使用不能による契約終了)

  1. 故障、事故または盗難により車両を使用できなくなったときは、代替車両による契約の継続について合意した場合を除き、その時点で貸渡契約を終了します。
  2. 当社の責めに帰すべき事由により契約が終了した場合は、未使用期間に対応する料金を返還します。損害賠償については法令に従って取り扱います。
  3. 当社および借受人のいずれにも責任のない事由により契約が終了した場合は、未使用期間に対応する料金を返還します。
  4. 借受人または運転者の責めに帰すべき事由により契約が終了した場合は、使用済み期間の料金および第27条による負担額を精算します。未使用期間の料金を当然に全額没収するものではなく、同一の損害について重複して請求しません。
  5. 契約終了後も、既に発生した精算義務、賠償責任および必要な返還協力義務は存続します。

第7章　賠償および補償

第27条 (賠償および営業補償)

  1. 借受人および運転者は、それぞれ自己の責めに帰すべき事由により、車両、付属品、装備品または第三者に損害を与えた場合、法令に従って賠償責任を負います。
  2. 当社は、修理費その他の損害を請求する場合、その内容および金額の根拠を説明します。通常の使用による摩耗および経年劣化は、借受人の負担としません。
  3. 借受人または運転者に責任のある事故、損傷、汚損等により営業上の損害が生じた場合は、契約前に提示した条件に従い、営業補償（ノンオペレーションチャージ。以下「NOC」といいます）を請求することがあります。対象事由、車両区分、自走の可否および金額は、保険・補償プランに掲載します。
  4. NOCと同一の営業上の損害について、重複して賠償を請求しません。
  5. 免責補償制度（CDW）に加入している場合は、契約前に提示した条件に従い、対象となる保険免責額の負担を免除します。対物・車両それぞれの対象範囲および免責額は、補償条件に明示します。NOCは、別途明示した場合を除き、CDWの対象に含まれません。
  6. 安心保証コース（PAP）に加入している場合の免除または補償の範囲は、契約前に提示した補償条件によります。
  7. 保険金が支払われない場合の取扱いは、保険会社の保険約款および判断によります。禁止行為があったことのみを理由に、すべての保険が一律に適用されないとするものではありません。
  8. CDWおよびPAPが適用されない事由は、契約前に提示する補償条件に明示します。当社は、適用を認めない場合、その理由および根拠となる条件を説明します。
  9. 保険金または補償制度によって填補された損害について、借受人に重複して請求することはありません。

第28条 (保険および補償)

  1. 当社の車両には、自動車損害賠償責任保険のほか、当社所定の任意保険を付保しています。
  2. 当社は、契約前に、対人、対物、車両および人身に関する補償の有無、限度額、免責額、主な適用除外その他重要な条件を提示します。
  3. 保険およびCDW・PAPの詳細は、契約時に適用する保険・補償プランおよび関連する補償条件によります。
  4. 借受人が法令上賠償責任を負う損害について、保険または補償制度で填補されない部分がある場合は、その責任の範囲で借受人の負担とします。
  5. 借受人および運転者は、保険金の請求に必要な書類の作成その他の手続きに協力するものとします。
  6. キッチンカーの調理設備、営業中の事故、食品、商品その他自動車保険の対象とならない損害の取扱いは、契約前に提示するキッチンカー利用特約および保険条件によります。

第8章　解除・解約

第29条 (契約の解除)

  1. 当社は、借受人が料金の支払いその他の契約上の義務を履行しない場合、相当の期間を定めて履行または是正を求め、その期間内に履行または是正がされないときは、法令に従って貸渡契約を解除することができます。
  2. 前項にかかわらず、次の場合その他法令により催告なく解除できる場合は、当社は催告することなく契約を解除し、直ちに車両の返還を求めることができます。
    1. 酒気帯び運転、無資格運転、無断転貸、犯罪への使用その他重大な禁止行為があった場合。
    2. 重要な事項について虚偽の申告があり、契約の継続が困難な場合。
    3. 借受人または運転者が反社会的勢力に該当することが判明した場合。
    4. 車両が返還されず、当社の連絡にも応じないなど、車両の安全な管理および返還が期待できない場合。
    5. 契約の継続により、人身、車両その他の財産に重大な危険が生じる具体的なおそれがある場合。
  3. 軽微な違反であり、契約の目的および取引上の社会通念に照らして解除が認められない場合は、解除しません。
  4. 解除時には、使用済み期間の料金、未払料金および借受人が負担すべき損害を精算し、受領済み料金に残額がある場合は返還します。
  5. 解除に伴う損害賠償は、法令および事前に提示した条件に従い、同一の損害について重複して請求しません。

第30条 (合意解約)

  1. 借受人と当社が合意した場合は、借受期間中であっても貸渡契約を解約することができます。
  2. 借受人の都合による合意解約の精算は、第20条第1項によります。
  3. 当社の責めに帰すべき事由による解約の場合は、未使用期間に対応する料金を返還します。
  4. 精算内容は、解約時に借受人へ説明します。
