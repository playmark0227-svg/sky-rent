個人情報のお取り扱いについて

当社は、貸渡契約の締結およびその履行のために、お客様の氏名、住所、電話番号、電子メールアドレス、運転免許証の記載事項その他の個人情報をお預かりします。お預かりした個人情報は、車両の貸渡し、料金の請求と精算、事故・故障・盗難への対応、法令にもとづく届出、ならびに当社からのご連絡およびサービスのご案内のために利用します。

当社は、法令にもとづく場合、保険金の請求その他の理由により保険会社へ提供する必要がある場合、事故の相手方または捜査機関からの正当な照会に応じる場合を除き、あらかじめお客様の同意なく個人情報を第三者に提供することはありません。利用目的、開示・訂正・利用停止のご請求方法など詳細は、プライバシーポリシーに定めるところによります。

お客様が必要な情報のご提供に応じられない場合、当社は貸渡契約の締結をお断りすることがあります。

第1章　総則

第1条 (約款の適用)

  1. この約款は、株式会社Skyward Growth (以下「当社」といいます) が「グロースレンタカー」の名称で行うレンタカーおよびキッチンカーの貸渡しについて、当社と借受人との間に成立する貸渡契約に適用します。
  2. この約款に定めのない事項については、法令または一般の慣習によります。
  3. 当社は、この約款の趣旨に反しない範囲において、書面による特約に応じることがあります。この場合、その特約はこの約款に優先します。
  4. この約款において「借受人」とは当社と貸渡契約を締結した方をいい、「運転者」とは貸渡証に記載された運転者をいいます。「車両」とは当社が貸し渡す自動車をいい、付属品および装備品を含みます。

第2章　予約

第2条 (予約の申込み)

  1. 予約のお申込みは、当社の予約サイト、電子メール、公式LINEその他当社が定める方法により承ります。
  2. お申込みに際しては、車両またはクラス、貸渡しの日時および場所、返還の日時および場所、借受人および運転者の氏名・連絡先、ご希望のオプションおよび補償、その他当社が必要と認める事項をお申し出いただきます。
  3. 予約は、当社がお申込みを承諾したときに成立します。
  4. 予約の成立は、当社が予約された内容で貸渡しの準備を行うことをお約束するものであり、貸渡契約そのものではありません。貸渡契約は第9条の定めにより成立します。

第3条 (予約の変更)

  1. 借受人は、貸渡しの開始前に限り、当社に対して予約内容の変更を申し出ることができます。
  2. 当社は、車両の空き状況その他の事情により、変更のお申し出に応じられない場合があります。
  3. 変更により料金に増減が生じるときは、別途定める料金表により精算します。
  4. 車両の変更を伴うなど、変更の内容が実質的に予約の取消しと新たな予約の申込みにあたると当社が認めるときは、当初の予約について第4条を適用します。

第4条 (予約の取消し)

  1. 借受人は、貸渡しの開始前に限り、いつでも予約を取り消すことができます。
  2. 予約が取り消されたときは、取消しのお申し出の時期および車両区分に応じて、別途定めるキャンセル規定によるキャンセル料をいただきます。金額は特定商取引法に基づく表記に掲げるとおりです。
  3. 貸渡しの開始予定時刻を経過してもご連絡がなく、当社が借受人に連絡を取ることもできないときは、当社は予約を取り消すことができます。この場合、無断キャンセルとしてキャンセル規定に定める額をいただきます。
  4. 天災、悪天候による交通の途絶、その他借受人の責めに帰することができない事由により予約された日時にご利用いただけないと当社が認めたときは、キャンセル料はいただきません。

第5条 (代替車両)

  1. 当社は、車両の故障、事故、先行する借受人からの返還の遅延その他の事由により予約された車両を提供できないときは、同等クラスの代替車両の提供に努めます。
  2. 代替車両の料金が予約された車両の料金を上回るときも、その差額はいただきません。下回るときは、代替車両の料金を適用します。
  3. 借受人が代替車両による貸渡しを承諾されないときは、予約は取り消されたものとし、キャンセル料はいただきません。

第6条 (免責)

  1. 当社は、前条の措置を講じてもなお車両を提供できなかったときは、その予約について既にお預かりした料金があるときはこれを返還します。
  2. 当社は、前項の場合において、借受人に生じた交通費、宿泊費、逸失利益その他の損害については、当社の責めに帰すべき事由がある場合を除き、責任を負いません。

第3章　貸渡し

第7条 (貸渡契約の締結)

  1. 貸渡契約は、借受人が営業所において当社所定の手続きを行い、当社が車両を引き渡すことにより締結します。
  2. 借受人および運転者は、手続きに際して有効な運転免許証をご提示ください。当社は、運転免許証その他の本人確認書類により確認を行い、その写しを取得することがあります。
  3. 運転者は、当該車両を運転するために必要な免許を有する方に限ります。
  4. 借受人が未成年である場合は、親権者その他の法定代理人の同意を必要とします。
  5. 借受人と運転者が異なる場合、借受人はこの約款にもとづく一切の義務について運転者と連帯して責任を負います。

第8条 (締結の拒絶)

当社は、次の各号のいずれかに該当するときは、貸渡契約の締結をお断りすることがあります。

  1. 借受人または運転者が有効な運転免許証を提示しないとき、または当該車両を運転するために必要な免許を有しないとき。
  2. 借受人または運転者が酒気を帯びていると認められるとき、あるいは薬物、疾病、疲労その他の理由により正常な運転ができないおそれがあると認められるとき。
  3. 借受人または運転者が暴力団その他の反社会的勢力に該当し、またはこれらと密接な関係を有すると認められるとき。
  4. 過去に当社の車両を損傷し、料金の支払いを怠り、またはこの約款に違反したことがあり、契約の履行が期待できないと認められるとき。
  5. 車両を第三者に転貸し、または当社の承諾なく営業の用に供するおそれがあると認められるとき。
  6. 申込みに際して事実と異なる申告があったとき。
  7. その他この約款に違反するおそれがあると認められるとき。

当社が貸渡契約の締結をお断りした場合、その予約は取り消されたものとして取り扱い、別途定めるキャンセル規定を適用します。また、これにより借受人に生じた損害について当社は責任を負いません。

第9条 (契約の成立)

  1. 貸渡契約は、当社が借受人に貸渡証を交付し、車両を引き渡した時に成立します。
  2. 借受期間は、貸渡証に記載した貸渡しの日時から返還の日時までとします。
  3. 貸渡証に記載された事項は、この約款の一部を構成します。

第10条 (貸渡料金)

  1. 貸渡料金は、基本料金、オプション料金、補償料金、割増料金その他別途定める料金表によります。料金はすべて消費税込みで表示します。
  2. 料金のお支払いは、原則として営業所における現地決済 (現金またはクレジットカード) によります。法人および行政機関のお客様は、事前の審査のうえ請求書払い (月次一括を含みます) をご利用いただけます。
  3. 当社は、オンラインでの事前決済を導入していません。
  4. 割引の適用条件、対象となる料金の範囲、超過料金および延滞に関する料金は、別途定める料金表によります。
  5. 有料道路料金、駐車料金、燃料代その他借受期間中に生じた実費は、借受人のご負担とします。

第11条 (借受条件の変更)

  1. 借受人は、借受期間中に返還の日時もしくは場所、または運転者を変更しようとするときは、あらかじめ当社に申し出て承諾を得るものとします。
  2. 当社は、その後の予約状況、車両の点検整備の予定その他の事情により、変更のお申し出に応じられない場合があります。
  3. 変更により料金に増減が生じるときは、別途定める料金表により精算します。

第12条 (点検整備及び確認)

  1. 当社は、貸渡しに際し、道路運送車両法に定める点検整備を行い、車両を安全に運行できる状態で引き渡します。
  2. 借受人は、車両の引渡しを受けるときに、当社係員の立会いのもとで、車両の外装および内装の状態、装備品、燃料の量、車検証その他の備付書類を確認するものとします。
  3. 前項の確認において、既存の傷、汚損、装備品の不足その他の異状を認めたときは、その場で当社にお申し出ください。お申し出のなかったものについては、返還時に判明した損傷等を借受期間中に生じたものとして取り扱うことがあります。

第13条 (貸渡証の交付・携帯)

  1. 当社は、貸渡しに際して借受人に貸渡証を交付します。
  2. 借受人は、借受期間中、貸渡証を車内に備え付け、または携帯するものとします。
  3. 借受人は、貸渡証を紛失し、または汚損したときは、速やかに当社にご連絡ください。

第4章　使用

第14条 (管理責任)

  1. 借受人および運転者は、善良な管理者の注意をもって車両を使用し、保管するものとします。
  2. 借受人は、運転者にこの約款を守らせる責任を負い、運転者の行為は借受人の行為とみなします。
  3. 借受人は、貸渡証に記載された運転者以外の者に車両を運転させてはなりません。
  4. 借受人および運転者は、車両を離れるときは必ず施錠し、鍵、貸渡証および車検証を適切に管理するものとします。

第15条 (日常点検整備)

  1. 借受人および運転者は、道路運送車両法に定める日常点検を行ったうえで車両を運行するものとします。
  2. 運行中に車両の異状を認めたときは、直ちに運行を中止し、安全な場所に停止させたうえで当社にご連絡ください。
  3. 借受期間中の燃料の補給および返還時の燃料の取扱いは、貸渡しの際に当社がご案内する方法によります。
  4. タイヤの空気圧、冷却水、ウォッシャー液等の点検により補充が必要となったときは、当社にご相談ください。当社の指示によらずに生じた費用は、当社が認めた範囲で負担します。

第16条 (禁止行為)

借受人および運転者は、次の各号の行為をしてはなりません。

  1. 酒気を帯びて、または薬物等の影響により正常な運転ができないおそれがある状態で運転すること。
  2. 車両を第三者に転貸し、または貸渡証に記載のない者に運転させること (又貸し)。
  3. 当該車両を運転するために必要な免許を有しない者が運転すること (無資格運転)。
  4. 当社の承諾なく、旅客または貨物の有償運送その他の営業の目的に車両を使用すること。
  5. 火薬類、高圧ガス、毒物その他の危険物または法令により運送が制限されている物品を輸送すること。
  6. 所定の措置 (ケージまたはキャリーの使用等) を講じずにペットを同乗させること。
  7. 車内で喫煙すること (加熱式たばこおよび電子たばこを含みます)。
  8. 乗車定員を超えて乗車させ、または最大積載量を超えて積載すること。
  9. 競争、競技、曲技もしくは試験に使用し、またはこれらに類する走行を行うこと。
  10. 車両を担保に供し、売却し、または当社の承諾なく改造し、部品もしくは装備品を取り外すこと。
  11. 当社の承諾なく、車両にステッカーの貼付、塗装その他外観を変更する行為を行うこと (キッチンカーの装飾を含みます)。
  12. 通行が禁止されている場所への乗り入れ、河川敷・海浜等の未舗装地の走行その他車両に著しい負担をかける使用をすること。
  13. 犯罪行為その他の違法な行為に車両を使用し、またはこれに供すること。
  14. 当社の承諾なく車両を国外に持ち出すこと。

これらの行為があったときは、当社は第29条により貸渡契約を解除し、車両の返還を求めるとともに、当社に生じた損害の賠償を請求します。また、車内喫煙、ペットの毛や臭気、著しい汚損等により特別な清掃または修復を要するときは、別途定める料金表による費用をいただきます。

第17条 (違法駐車の措置)

  1. 借受人および運転者は、借受期間中に生じた駐車違反その他の交通法規違反について、自らの責任と負担において処理するものとします。
  2. 放置駐車違反があったときは、借受人または運転者は速やかに警察へ出頭し、反則金の納付その他の手続きを行うとともに、その旨を当社にご連絡ください。
  3. 前項の手続きが行われなかったことにより、当社が車両の使用者として放置違反金の納付命令を受けたときは、借受人はこれを負担するものとし、当社が納付したときは、当社に対しその額および当社所定の事務手数料をお支払いいただきます。
  4. 当社は、違反の処理が完了するまでの間、借受人に対し必要な報告および協力を求めることがあります。

第5章　返還

第18条 (返還責任)

  1. 借受人は、貸渡証に記載した返還の日時までに、返還場所において車両ならびに付属品、装備品、鍵、貸渡証および備付書類を返還するものとします。
  2. 返還は、当社の営業時間内 (北見本店 9:00〜19:00 / 釧路店 9:00〜18:00) に、当社係員の立会いのもとで行っていただきます。
  3. 返還が遅れるおそれがあるときは、返還の日時までに必ず当社にご連絡いただき、承諾を得るものとします。
  4. 借受人の責めに帰すべき事由により車両を返還場所まで返還できないときは、車両の回収に要する費用は借受人のご負担とします。

第19条 (返還時の確認)

  1. 当社は、返還に際して当社係員の立会いのもと、車両の外装および内装の状態、装備品、燃料の量、走行距離を確認します。
  2. 確認の結果、損傷、汚損、装備品の不足その他の異状が認められたときは、当社はその内容を記録し、第27条の定めにより取り扱います。
  3. 当社が特に認めて立会いによらない返還を行った場合は、当社が車両を確認した時点の状態をもって返還時の状態とします。

第20条 (借受期間変更時の料金)

  1. 借受人が返還の日時を繰り上げて車両を返還したときも、原則として当初の借受期間に対応する料金をいただきます。
  2. 返還の日時を繰り下げたときは、超過した時間または日数に応じて、別途定める料金表による超過料金をいただきます。
  3. 当社の承諾を得ずに返還の日時を経過したときは、前項の超過料金に加えて、別途定める延滞に関する料金をいただきます。
  4. 前2項の料金の額は特定商取引法に基づく表記および車両と料金に掲げるとおりです。

第21条 (返還場所)

  1. 返還場所は、貸渡証に記載した営業所とします。
  2. あらかじめ当社の承諾を得た場合に限り、他の営業所において返還することができます。この場合、別途定める料金をいただくことがあります。
  3. 当社の承諾なく車両を返還場所以外の場所に置き去りにしたときは、借受人は、車両の回収に要した費用および回収が完了するまでの期間に対応する超過料金を負担するものとします。

第22条 (不返還の措置)

  1. 返還の日時を経過しても車両が返還されず、かつ借受人が当社の連絡に応じないときは、当社は貸渡契約を解除し、車両の引揚げその他必要な措置をとることができます。
  2. 当社は、前項の場合において、警察へ届け出ることがあります。
  3. 借受人は、車両の引揚げに要した費用、返還されるまでの期間に対応する料金、および当社に生じた損害を負担するものとします。

第6章　故障・事故・盗難

第23条 (故障時の措置)

  1. 借受期間中に車両に故障または異状が生じたときは、直ちに運行を中止し、安全な場所に停止させたうえで当社にご連絡ください。
  2. 借受人および運転者は、当社の指示によらずに修理、部品交換その他の措置を行ってはなりません。やむを得ずこれらを行ったときは、当社が認めた範囲で費用を負担します。
  3. 故障が借受人の責めに帰すべき事由によらないときは、当社は代替車両の手配または修理の手配に努めます。

第24条 (事故時の措置)

  1. 借受期間中に事故が生じたときは、直ちに運行を中止し、負傷者の救護および道路上の危険防止その他法令に定める措置を講じたうえ、直ちに警察へ届け出るとともに、当社にご連絡ください。
  2. 借受人および運転者は、当社の指示に従い、事故の状況、相手方の氏名および連絡先、加入保険その他必要な事項を当社に報告し、交通事故証明書その他の書類の取得に協力するものとします。
  3. 借受人および運転者は、当社の承諾なく事故の相手方と示談その他の合意をしてはなりません。
  4. 警察への届出または当社への連絡を怠ったときは、保険および補償制度の適用を受けられないことがあります。

第25条 (盗難時の措置)

  1. 車両、付属品または装備品が盗難に遭ったときは、直ちに警察へ届け出るとともに、当社にご連絡ください。
  2. 借受人は、盗難届の受理番号その他当社が必要とする事項を当社に報告するものとします。
  3. 鍵の管理を怠るなど、借受人または運転者の責めに帰すべき事由による盗難については、第27条の定めにより損害を賠償していただきます。

第26条 (使用不能による契約終了)

  1. 故障、事故または盗難により車両を使用できなくなったときは、当社が代替車両を提供する場合を除き、貸渡契約はその時点で終了します。
  2. 前項により契約が終了したときは、使用できなかった期間に対応する料金は、当社の責めに帰すべき事由によるときに限り返還します。
  3. 契約が終了した後においても、第27条の賠償に関する責任および第5章に定める返還に関する義務は存続します。

第7章　賠償及び補償

第27条 (賠償及び営業補償)

  1. 借受人および運転者は、故意または過失により車両、付属品もしくは装備品を損傷し、滅失させ、または第三者に損害を与えたときは、当社および第三者に対してその損害を賠償するものとします。
  2. 前項の場合、車両の修理に要する費用のほか、車両を営業に使用できない期間について、当社所定の営業補償 (ノンオペレーションチャージ) をいただきます。その額は、車両区分および自走の可否に応じて、別途定める料金表によります。詳細は保険・補償プランをご覧ください。
  3. 免責補償制度 (CDW) にご加入いただいている場合、車両の損傷についてお客様にご負担いただく免責額を免除します。ただし、営業補償は免責補償制度の対象に含まれません。安心保証コース (PAP) の補償範囲は、別途定める補償制度の内容によります。
  4. 次の各号のいずれかに該当するときは、保険および補償制度の適用を受けられず、損害の全額を借受人にご負担いただくことがあります。
    • 酒気帯び運転、薬物等の影響下での運転または無資格運転があったとき。
    • 第16条の禁止行為に違反したとき。
    • 事故について警察へ届け出なかったとき、または当社への連絡を怠ったとき。
    • 申告の内容が事実と異なるとき。

第28条 (保険及び補償)

  1. 当社の車両には、自動車損害賠償責任保険のほか、当社所定の任意保険を付保しています。
  2. 保険の補償範囲および限度額、免責補償制度 (CDW) ならびに安心保証コース (PAP) の内容および料金は、別途定める補償に関する定めによります。保険・補償プランをご確認ください。
  3. 保険金が支払われるときは、その範囲において借受人の賠償責任は免除されます。保険金の額が損害の額に満たないときは、その差額は借受人のご負担とします。
  4. 借受人および運転者は、保険金の請求に必要な書類の作成その他の手続きに協力するものとします。

第8章　解除・解約

第29条 (契約の解除)

  1. 当社は、借受人または運転者が次の各号のいずれかに該当するときは、催告することなく貸渡契約を解除し、直ちに車両の返還を求めることができます。

第30条 (合意解約)
